# Campaign Ready Assets

Approved promotional assets live here.

Naming convention:

- Folder: `{Campaign}/{Subject}_{Number}/`
- Image: `{Campaign}_{Subject}_{Number}_approved_image.png`
- Caption: `{Campaign}_{Subject}_{Number}_approved_text.md`
- QA crop: `{Campaign}_{Subject}_{Number}_frame_crop_QA.png`
- Source notes: `{Campaign}_{Subject}_{Number}_production_notes.md`

Keep approved images and their approved text in the same folder so campaign posts can be assembled without guessing which caption belongs to which visual.
