# Beatles TYLS Campaign Assets

Source originals remain untouched in:

/home/Phil/Claude/Claude-Projects/PickArt/Media-Bible-Project/beatles

## Folders

- `enhanced/` - campaign-ready versions with deeper blacks, gentle contrast, and light sharpening.
- `contact_sheets/` - quick visual review sheets.

## Intended Use

Use these enhanced images as the print source when creating framed in-situ promotional material, such as luxury listening rooms, modern interiors, studies, private bars, and gift-positioning creative.

Do not use these to replace the Media Bible catalogue originals unless explicitly decided later.

Suggested honesty line for room mockups:

"Shown framed for inspiration. Limited edition archival print supplied unframed."
